### **Tailwind에서 반응형(`grid-cols-2`, `grid-cols-4`)이 동작하는 원리** Tailwind CSS에서는 `sm`, `md`, `lg`, `xl` 등의 **반응형 브레이크포인트(Breakpoints)**를 사용하여 특정 화면 크기 이상에서만 스타일을 적용할 수 있습니다. --- ### **📌 Tailwind의 기본 반응형 브레이크포인트** | Tailwind 클래스 | 적용되는 화면 크기 (px) | |--------------|----------------| | `sm:` | **640px 이상** | | `md:` | **768px 이상** | | `lg:` | **1024px 이상** | | `xl:` | **1280px 이상** | | `2xl:` | **1536px 이상** | --- ### **📌 적용 원리** ```html
``` 1. **모바일 (기본값, 0~767px)** - `grid-cols-2` → **2개의 컬럼 배치** ``` [1번] [2번] [3번] [4번] ``` 2. **태블릿 & 데스크톱 (`md:grid-cols-4`, 768px 이상)** - `grid-cols-4` → **4개의 컬럼 배치** ``` [1번] [2번] [3번] [4번] ``` --- ### **📌 실제 동작 테스트** ✅ **윈도우 크기를 줄이거나 개발자 도구(F12) → 반응형 모드(Toggle Device Toolbar)를 사용하여 확인 가능!** (Chrome에서 `Ctrl + Shift + M` 또는 `F12` → `기기 모드`) ✅ Tailwind 공식 사이트에서 `grid-cols-2 md:grid-cols-4` 클래스 실험 가능: 👉 [Tailwind Play (실제 테스트)](https://play.tailwindcss.com/) --- ### **🔥 결론** - Tailwind의 `md:` 접두어는 **768px 이상**일 때만 적용됨. - **모바일(작은 화면)**에서는 `grid-cols-2` 적용 → 2개씩 배치. - **태블릿/데스크톱(768px 이상)**에서는 `grid-cols-4` 적용 → 4개씩 배치. - 윈도우 크기를 변경하거나, 개발자 도구에서 직접 확인 가능. 🚀
